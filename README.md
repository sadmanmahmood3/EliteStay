# EliteStay - Hotel Booking Management System

EliteStay is a web-based Hotel Booking Management System designed to make the hotel reservation process simple and convenient for customers while helping hotel administrators manage rooms and bookings efficiently.

## Project Overview

EliteStay allows customers to browse available hotel rooms, select their preferred room, provide booking information, and confirm their reservation. The system also provides an administrative section where hotel staff can manage bookings and monitor reservation information.

The project covers the complete hotel booking process, starting from checking room availability to confirming a reservation.

## Main Features

### Customer Features

- View available hotel rooms
- Check room availability
- View room details and booking information
- Select a room for booking
- Enter customer and reservation information
- Make a room reservation
- Receive booking confirmation
- View booking information
- Manage customer profile

### Admin Features

- Admin login and dashboard
- View all hotel bookings
- Monitor customer reservations
- Manage booking information
- View available rooms
- Manage hotel room-related information
- Access customer and booking details

## Hotel Booking Procedure

The general booking process of EliteStay is:

1. **Visit the Website**
   - The customer opens the EliteStay hotel booking website.

2. **Browse Available Rooms**
   - The customer checks the available rooms and their information.

3. **Select a Room**
   - The customer chooses a suitable room based on availability and requirements.

4. **Book the Room**
   - The customer proceeds to the booking page and provides the required information.

5. **Enter Customer Information**
   - The customer provides necessary details such as name, contact information, and booking-related information.

6. **Submit Booking**
   - The booking information is submitted to the system.

7. **Booking Confirmation**
   - The system processes the reservation and displays a booking confirmation.

8. **Admin Management**
   - The booking information becomes available to the administrator through the admin dashboard.

9. **Booking Monitoring**
   - The administrator can view and manage customer bookings and reservation information.

## System Modules

### 1. Customer Module
Handles customer registration/profile information and customer-related activities.

### 2. Room Module
Displays available rooms and provides information required for customers to select a room.

### 3. Booking Module
Handles the complete room reservation process, including booking details and reservation submission.

### 4. Booking Confirmation Module
Provides confirmation information after a successful booking.

### 5. Admin Module
Allows administrators to access the dashboard and manage hotel bookings and related information.

## Project Structure

The project contains separate files for different parts of the hotel booking system, including:

- `admin_dashboard.php` - Admin dashboard
- `admin_bookings.php` - Manage and view bookings
- `availableRooms.php` - Display available rooms
- `bookNow.php` - Room booking page
- `booking.php` - Booking process
- `bookingConfirmation.php` - Booking confirmation
- `customerBooking.php` - Customer booking information
- `customer_profile.php` - Customer profile
- CSS files - Website styling
- JavaScript files - Client-side functionality
- `composer.json` - Project dependency configuration

## Purpose of the Project

The main purpose of EliteStay is to provide a convenient online platform for hotel room reservations and to reduce the manual work involved in managing hotel bookings.

The system connects customers and hotel administrators through a centralized booking platform, making the reservation and booking management process more organized and efficient.
